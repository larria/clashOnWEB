## 2026-09-20 修复首次播放音效被吞(加载竞态)

- 症状:开场一段时间内部署音时有时无(火枪手/巨人等)
- 根因:音效懒加载(fetch+decode 异步),首次 play() 时 buffer 未就绪
  → 直接 return 静默丢弃;该音第二次起才正常——竞态随时机表现为"有时有"
- 修复:
  · pending 队列:加载完成前的播放请求排队,decode 完成即补播
    (每音一个防堆积;高频脚步音不排队静默跳过)
  · 开局预加载:bindGame 批量预载 14 个高频核心音(号角/塔击/死亡/皇冠等)
  · 选牌预加载:选中卡牌即预取该卡的部署/攻击/脚步/法术音
    (选卡到落卡的几秒窗口内就绪,部署音必定有声)
- 验证:未加载音首播触发拉取且补播链路无错;核心音 7/7 预载;
  2 局回归无异常
