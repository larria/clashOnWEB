# 皇室战争 单机 Web 版

基于 HTML5 Canvas 的皇室战争玩法还原,纯前端实现,无任何依赖,浏览器直接打开即玩。

## 玩法

- 18×32 格战场:双路 + 河道 + 双桥,每方 2 座公主塔 + 1 座国王塔
- 圣水系统:10 费上限,每 2.8 秒回复 1 费,2 分钟后双倍圣水
- 手牌循环:4 张手牌 + 1 张下一张,出牌后按顺序循环(与原版一致)
- 胜负:摧毁对方国王塔立即获胜;3 分钟超时按皇冠数/塔血判定

## 操作

1. 点击下方手牌选中卡牌
2. 点击己方半场(河道下方)部署部队/建筑;法术可全场释放
3. 选中卡牌后 canvas 上有部署预览

## 卡牌(42 张)

**部队 24 张**
- 普通:骑士、弓箭手、哥布林、投矛哥布林、骷髅兵、亡灵、野蛮人、炸弹兵
- 稀有:巨人、迷你皮卡、火枪手、女武神、野猪骑士、法师
- 史诗:皮卡超人、王子、飞龙宝宝、骷髅军团、女巫、气球兵、骷髅巨人、戈仑石人、亡灵大军

**建筑 10 张**:加农炮、特斯拉电磁塔、地狱之塔、炸弹塔、哥布林小屋、野蛮人小屋、骷髅墓碑、圣水收集器、X连弩、迫击炮

**法术 8 张**:火球、万箭齐发、火箭、雷电法术、电击法术、狂暴法术、冰冻法术、镜像法术

## 已实现的机制

- 寻路:地面单位走桥过河,飞行单位直线
- 索敌:视野内最近目标;行军中遇到更近敌方单位会转移目标;只打建筑的单位(巨人/野猪/气球)无视部队
- 特殊技能:王子冲锋、地狱塔递增伤害、女巫/小屋持续产兵、气球/骷髅巨人/戈仑石人死亡伤害与分裂、墓碑死亡召唤、圣水收集器产费、冰冻/狂暴/电击眩晕/镜像复制
- 塔攻击状态显示:瞄准线、射击闪光、装填条

## AI 对手

- 基于 counter 表的针对性防守(30+ 威胁卡对应解牌)
- 攻防节奏控制、坦克+后排组队推进、法术补刀与解场
- 与玩家使用相同卡组,决策频率可调(普通/困难/挑战)
- 经自动化对局测试,AI 对同等决策水平的对手胜率 67%+

## 技术

纯 HTML + CSS + JavaScript(约 2300 行),Canvas 2D 渲染,无构建步骤、无依赖。

```
index.html      入口
js/constants.js 战场常量与坐标系
js/cards.js     42 张卡牌数据
js/unit.js      单位类
js/tower.js     塔类
js/combat.js    寻路/索敌/攻击/伤害结算
js/spells.js    法术系统
js/game.js      游戏主循环/胜负判定
js/ai.js        AI 决策
js/renderer.js  Canvas 渲染
js/main.js      交互/UI/日志
```

## 运行

直接用浏览器打开 `index.html`,或:

```bash
cd clash && python3 -m http.server 8000
# 访问 http://localhost:8000
```
